# 账号与会员 · 1.24.0

按接近、对齐、重复、对比统一账号及订单页。账号操作放在第一张卡片，会员状态、额度和最后同步时间合并为一个区块，套餐与订单分开。权益说明默认收起，避免首次进入出现长篇说明。

主要路径为“账号登录 / 注册 → 会员与额度 → 套餐订单”。登录失效时直接显示重新登录；忘记密码保留已填账号。返回按钮置于弹窗顶部，表单支持键盘避让及滚动。恢复码必须确认保存，复制反馈提醒安全保存，不引导粘贴到聊天。

错误不靠颜色单独表达：离线显示上次状态及待同步，令牌失效清除旧会员展示，付款到账但会员刷新失败明确提示重试。未开放收款时保留免费功能和历史订单入口。

按钮至少 48dp，操作行允许换行；弹窗内容最大宽度 600dp。套餐价格和有效期分行，金额、会员状态、说明形成字号层级；200% 系统字体使用可滚动内容，避免固定高度裁切。

本轮在 Android 11 模拟器 320×640 mdpi 检查正常/200% 字号、账号恢复及订单状态。截图中的账号、金额、订单均为回环测试夹具；不代表真实支付或微信/QQ 验收。
