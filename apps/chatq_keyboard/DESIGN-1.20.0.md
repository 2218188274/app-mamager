# 安卓键盘表情与排版规范 · 1.20.0

## 四大原则如何落地

| 原则 | 本版实现 | 检查点 |
| --- | --- | --- |
| 对比 Contrast | 当前分类使用淡紫底；图片预览只保留一个实心主按钮。正文、次要说明、危险反馈采用不同字重和颜色。 | 不让返回、切换、使用同时抢占视觉注意力。错误使用文字说明，不只变色。 |
| 重复 Repetition | 与主应用共用品牌紫 #7054C8、原创云朵表情和文字表情目录；圆角卡片、选中状态、48 dp 操作高度保持一致。 | 表情、颜文、图片切换后工具栏位置不变；主应用与键盘同名表情不漂移。 |
| 对齐 Alignment | 四个工具入口等宽；卡片网格等列、同边距；预览与主按钮左右对齐。 | 320 dp 小屏、深色及大字号截图逐项检查，图标不挤占文字。 |
| 亲密性 Proximity | 分类靠近表情网格；使用提示靠近图片；主操作固定在预览底部。隐藏无关的拼音提示与候选栏。 | 相近功能组成一组；不把图片操作与空格、回车混排，不额外堆叠工具条。 |

## 字体、触控与适配

- 工具按钮与表情名称 14 sp，组标题 16 sp / 加粗，辅助说明 12 sp。语义文字跟随系统字号。
- Emoji 是图形内容，使用 28 dp 字形与 52 dp 单元格，不随系统文字放大到裁切；TalkBack 使用完整含义标签。字号 200% 时网格由 5 列减至 4 列；颜文字由双列减至单列；图片由 3 列减至 2 列。
- 表情页操作目标至少 48 × 48 dp。高密度字母键保留传统键盘的十列几何布局，不声称所有字母键也达到 48 dp 宽。
- 大字号时隐藏可选的长按角标，优先显示主键字；“打字、表情、颜文、图片”使用短可见标题与完整无障碍名称。
- 使用 4/8/12/16 dp 间距序列和 12/14/18 dp 分层圆角。表情面板高度固定、内容滚动，预览主按钮固定（横屏右侧，竖屏底部）；返回打字始终位于左上。
- 浅色正文 #28243D、辅助文字 #625D74，白卡片；深色正文 #EDEBF5、辅助文字 #BDB6CD，卡片 #303044。选中状态同时带颜色和 selected 属性。

## 图片交付边界

1. 三款本地原创图片，用户点卡片仅预览，不提交。
2. Android 7.1+ 且编辑器声明 image/png、image/* 或 */* 时，明确点击“使用表情”后以临时只读 content URI 交给当前编辑器。
3. 接收应用决定如何处理图片，可能直接发送；预览提示这点。键盘不主动调用发送/回车，不宣称所有接收方都会先放进草稿。
4. Android 7.0 或不支持 PNG 的输入环境使用系统分享，用户选择应用和联系人；拒收不会自动分享或自动重试。
5. 密码、隐私、邮箱/网址等专用输入框不启用图片交付；切换输入框、隐藏键盘、退出预览、切换分类使旧请求失效。
6. 缩图与文件准备在独立线程执行，不阻塞拼音或 AI 工作线程；仅缓存三张缩略图。文件路径与表情 ID 白名单限制在专用缓存目录。

## 验证与限制

自动化使用独立离线编辑器，覆盖 PNG 跨应用权限和解码、MIME 通配符、拒收、分享取消、预览返回、系统返回、专用输入框和文字不自动发送。相关拼音与 AI 工作流采用离线词库、回环 HTTP 测试，避免收费请求。测试结果和截图见本版 validation/audit 文件。

微信/QQ 真机图片接收能力、不同厂商系统分享体验仍需实际设备确认；不能将测试编辑器结果称为微信/QQ 真机通过。当前安装包仍沿用内部测试签名，不是应用商店正式发行签名。

参考：[Android 图片键盘协议](https://developer.android.com/develop/ui/views/touch-and-input/image-keyboard)、[Android 无障碍指南](https://developer.android.com/guide/topics/ui/accessibility/apps)。

对比度计算：白色主按钮文字对品牌紫为 5.54:1；辅助文字对键盘浅底为 5.57:1；品牌紫对浅紫选中底为 4.71:1；深色卡片正文为 10.91:1。
