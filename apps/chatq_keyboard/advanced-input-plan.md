# Android 1.4.0 input expansion

1. Bundle attributed, version-pinned Rime pinyin data for an offline digit-to-pinyin nine-key decoder, and a frequency-ranked English dictionary for local suggestions, conservative boundary correction and immediate backspace undo.
2. Add per-user keyboard preferences for QWERTY/nine-key, English correction and optional cloud candidates. Cloud requests send only the composing code, never surrounding text, and are disabled in secure/private editors. Preserve offline candidates and discard stale responses.
3. Add explicit microphone recording with runtime permission, cancel/stop controls, a 20-second limit, recognition preview and explicit insertion into the original editor. Host an isolated multilingual Whisper service behind authenticated app endpoints; keep recordings transient and enforce size, format, concurrency and rate limits.
4. Add a licensed larger server-side lexicon, protected lookup/version routes, validation tests and deployment configuration. Preserve the deployed AI/persona changes when syncing server sources.
5. Verify new native algorithms, existing editor interactions, nine-key ambiguity/prefix handling, correction/undo, private fields, cloud failures and real audio recognition. Build, sign, publish and hash-check the 1.4.0 APK; preserve 1.3.0 and document physical microphone validation limits.

Completed 2026-10-21. The 1.4.0/code 5 arm64 APK is published, signature/16K alignment verified, and its full public HTTP download matches the local SHA-256. Final offline runs passed 32 existing editor cases and 14 nine-key/English cases. Actual Kotlin instrumentation passed 34 engine/settings/WAV/session checks, plus real cloud and explicit voice-preview editor tests. The deployed multilingual base model recognized the Chinese/English test audio in 5.53/4.86 seconds; the prior small model was slower and remains optional. Twelve mobile tests, 14 server tests, strict TS builds, release lint and clean iOS source-structure verification passed. The physical handset microphone and iOS compilation remain outside what has been verified. See artifacts/ChatQ-1.4.0-validation.md and server/deploy/INPUT-DEPLOYMENT.md.
