# 聊商手机端

当前 Android 1.28.2 为免费自备 API 模式。主应用和安卓键盘直接调用用户配置的 OpenAI 兼容 Chat Completions 接口，不通过聊商转发，不要求登录或购买会员。密钥使用 Android Keystore + AES-GCM 保存在本机独立存储中，不返回 JS、不进入平台账号、同步或备份。平台账号、目录、云词库与语音服务仍使用原平台连接配置。iPhone 工程尚未实现本轮个人 API 原生桥接，也未编译验证。

## 开发与打包

1. `npm ci`，复制 `.env.example` 为 `.env.local`，填写后台应用的连接码（不是 AI 供应商密钥）。
2. `npm run check`、`npm test`。
3. `npx expo prebuild --platform android --no-install`。
4. 安装 JDK 17、Android SDK 36、Build Tools 36、NDK 27.1.12297006、CMake 3.22.1。Windows 建议复制到短的纯英文目录构建。
5. 在 android 目录执行 `gradlew :app:assembleRelease -PreactNativeArchitectures=arm64-v8a`。Release 包包含 JS，不需要 Metro。当前内测使用模板的调试签名；正式发布前配置自己的签名并妥善备份。

## Android 使用

安装 APK → 打开聊商 → 我的 → 开始使用与自检，按顺序配置自己的 API、启用并选择聊商键盘，再在本页试打。默认进入离线拼音，输入 `nihao` 后点“你好”或空格选首选词。左右滑动候选栏查看更多；先选择部分词时保留剩余拼音。`v` 表示 ü，点击“分词”输入隔音符，例如 `xi'an`。退格先删除拼音，清空后删除正文。输入过程中点换行只确认当前拼音，再点才执行换行/输入框动作。中英文和数字模式可直接切换。

AI 回复：点顶部“AI/话题 → 写回复”展开，复制对方消息后点击“粘贴消息”，选语气、数量并生成，点击候选填入。输入法不会自动点击发送。密码框禁止 AI 并采用直接输入；邮箱和数字框自动切换。切换输入框后取消旧请求并清除候选。

主应用提供直接生成、复制回复及本地 SQLite 记录。安卓键盘与主应用共用生成记录，可在记录页关闭保存。仅主动点击生成时上传本条消息，不自动扫描聊天窗口，也不监听剪贴板。

## 人设与场景（1.2.0）

主应用“人设”页可从后台人设包创建卡片，也可自定义名称、说话习惯、回复长度，以及最多 20 个性格标签和强度。保存后立即设为默认；最多保留 20 张卡，可编辑或删除。关系和场景从后台获取，选“不指定”则不添加该条件。回复页支持补充本次背景（200 字）和回复目标（80 字）。

系统键盘展开 AI 面板后，顶部三个下拉框分别切换人设、关系和场景。更改会清除旧候选并取消旧请求，下一次生成使用新选择。主应用回到前台时读取键盘选择；键盘重新打开时读取主应用设置。人设定义和选择分开保存到 SharedPreferences / App Group，卡片编辑不会覆盖键盘的快捷选择。人设为本机设置，不自动跨手机同步。

实际请求通过 `customPrompt`、`personaTagWeights`、`sceneId`、`relationId`（主应用可再带 `context`）提交已有接口。后台解析标签、场景和关系名称，语气与人设同时生效。人设包缓存按服务器和应用隔离；离线保留已有卡片、场景和过期缓存，联网后可手动刷新。新增后台模板不会自动替换用户修改过的卡片。

自动验证覆盖人设请求字段、保存/删除回退、原生共享配置、损坏存储、离线目录和应用隔离。`node --test tests/ios-project.test.cjs` 检查生成的 iPhone 工程，不能替代 Xcode 编译。

## 安卓日常输入（1.3.0）

字母按 QWERTY 错位排列，空格键加宽。英文点 ⇧ 输入一次大写，快速双击锁定大写，再点解除；长按第一排字母输入对应数字，长按删除连续退格。横向滑动空格移动光标，不会额外插入空格。候选栏右侧箭头展开为可滚动选词面板。

123 页提供数字、小数点、正负号和电话符号；符号页有中文/英文标点及第二页扩展符号。顶部“表情”提供两页表情，退格按 Unicode 字符组合删除。顶部“编辑”提供方向键、行首行尾、选择开关、全选、复制、剪切和粘贴；仅在点击时操作，不保存剪贴板。输入框的搜索、发送、下一项和完成动作使用系统接口；多行框遵循不发送的标记。

顶部“设置”可调整震动、按键音、数字行、本地记词、按键高度和主题；管理常用词会打开主应用“键盘偏好与常用词”。可增加简拼码对应的姓名、词语和短语，搜索、删除或清空本机词库。最多 300 条，全部保存在本机。自动记词仅记录主动选中的短词和拼音码，可关闭；密码框和禁止个性化的输入框不记词，自定义词仍可手动使用。本机词库不会上传；手动开启云词库后，仅查询当前拼音码。

AI 面板占用键盘区域，不再叠加在字母键盘上；保留原有人设、场景和真实 AI。iPhone 工程保留此前功能，本节新增的布局与偏好仅适用于安卓。

原生回归：使用 `tests/build-android-fixtures.ps1` 构建 fixture 和 instrumentation 测试 APK，在模拟器安装后运行 `adb shell am instrument -w com.chatq.keyboardtests/.KeyboardInstrumentation`。默认模式只读写独立的测试偏好文件，并通过本机 HTTP fixture 检查网络客户端。`tests/android-daily-ui.ps1` 使用 320×640 mdpi 模拟器，通过实际输入框核对文字和编辑动作；运行前打开聊商主应用，再选择聊商键盘，使用标准高度/无数字行/默认中文。`prepareUi` 模式可准备偏好；instrumentation 结束会停止目标应用进程，之后运行独立 UI 脚本前应重新打开主应用和选择输入法。快速双击使用 fixture 的 UI instrumentation，避免 adb 每次启动命令造成的手势间隔失真。

## 安卓输入增强与稳定性（1.4.0 / 1.4.1）

键盘设置中切换全键盘 / 九宫格；九宫格使用本机 6.5 万条词条，输入后可点“选音”。英文输入空格或正文标点时可自动纠错，紧接退格撤销；长按原文可记住专有词。数字后缀不触发纠错，邮箱、网址和密码采用直接输入。

主应用“键盘偏好”可手动开启云词库，默认关闭。云候选带 ☁，只查询当前组合码，禁用于密码或禁止个性化的输入框；断网继续本机输入。请求有超时和取消保护，候选只应用于相同组合码，缓存按连接配置隔离。

点击顶部“语音”后手动开始录音，最长 20 秒；结束后点击识别上传至自己的服务器，确认预览后返回键盘，再点“填入文字”。结果只用于原输入框，不自动发送。超时提供重新返回的入口；离开录音界面取消录音与请求。语音部署见 server/deploy/INPUT-DEPLOYMENT.md。

1.4.1 修复英文展开候选确认原文后仍留在展开面板的问题，补充输入连接重启与外部光标/文字变化的状态清理，并在隐藏键盘时取消未完成 AI 请求。“设置”页顶部显示“返回打字”。

`tests/android-native/KeyboardInstrumentation.java` 的 `stabilityUi` 模式验证实际编辑器的重启、外部替换、光标、英文纠错/撤销、连续输入、长按删除、设置返回和语音会话失效。默认模式还使用本机 HTTP fixture 验证网络超时、取消、响应大小及取消后重连，不连接真实 AI。`aiUi` 模式才会主动请求一次真实 AI；`cloudUi` 与 `voiceUi` 分别验证真实云候选和手动语音结果填入。

## 安卓聊天候选与联想（1.5.0）

全拼与九宫格共用本机中文词库，并补入 109 条常用聊天短语。全拼支持这些短语的简拼，如 `wzdl → 我知道了`、`mwt → 没问题`。九宫格提供词频排序、少量后续拼音补全和多词组合候选；展开候选显示拼音读音。整句也可先选前面的词，剩余数字继续组合。已选常用词可在后续长句中作为部分候选，学习排序保留原有拼音分隔。

选择中文词语后，候选栏显示本地联想，例如“你好 → 呀”“辛苦 → 了”，以及常用短语的后半段。仅点选才填入；空格仍输入空格。App“键盘偏好”可关闭联想。联想只使用本次主动选中的词，不读取聊天记录或剪贴板，不额外上传数据；移动光标、标点、切换输入框及隐藏键盘会清除上下文。密码和禁止个性化的输入框停用联想。

词库索引在打包时生成，运行时共享加载；解码缓存有数量上限，用户词排序每次重新应用。普通候选栏复用最多 14 个按钮，展开面板保留完整列表。云候选到达时保留正在按住的目标和横向滚动位置，过期候选不会填入别的组合码。自动记词使用后台磁盘写入，手工增删常用词仍同步确认保存。

重新生成本机数据：`node scripts/build-typing-data.cjs --offline`；校验摘要见 `typing-data.json`。原始词库许可与项目自编聊天补充见包内 typing-NOTICE.txt。`candidateUi` instrumentation 验证真实编辑器中的候选与联想，`candidateBench` 测量共享词库冷加载、缓存查询及不同九宫格数字的查词时间；计时不等同于真实手机整帧响应。

## iPhone 工程

在 macOS / Linux 运行 `npx expo prebuild --platform ios --clean --no-install`。插件自动添加 ChatQKeyboard 扩展、Swift / Objective-C++ / C++ 源码、桥接头、离线词库资源、Info.plist、App Group、宿主依赖及嵌入阶段。`modules/chatq-keyboard/ios` 通过 CocoaPods 自动链接到主应用。已有自定义原生改动时先备份；本仓库的原生工程由模板生成。

使用 Mac 安装 Pods，打开生成的 `.xcworkspace`；为宿主 `com.jaxon.app.chatq` 和扩展 `com.jaxon.app.chatq.keyboard` 选择同一开发团队，启用 `group.com.jaxon.app.chatq`。安装后添加聊商键盘并开启“允许完全访问”，用于网络与共享配置。Apple 账号、签名、Xcode 编译和真机调试尚需在 Mac 上完成。本次不提供 IPA。

## 当前范围

- 支持真实 AI、1–3 条候选请求、4 种语气、点击填入、拼音/字母/数字/符号键盘、切换输入法。实际候选数量及免费额度由后端套餐控制。
- 已加入离线全拼、简拼、词组/整句候选、分词符、中英文切换、中文标点、组合区退格。默认离线，不消耗 AI 额度。安卓还支持九宫格、可选云词库、语音和英文纠错；未实现滑行输入。
- 当前按要求通过服务器 IP 使用 HTTP；Android 仅对该 IP 和本地调试地址放行。iOS 内测 ATS 允许 HTTP。正式发布需配置 HTTPS 并收紧 ATS。
- 修改 app.config.js 或原生插件后重新 prebuild；不要使用 Expo Go 验证系统键盘。

## 话题库与 AI 找话题（1.6.0）

主应用底部“话题”或“回复”页的入口可打开话题库。8 类共 64 个自编话题，每条有开场白和接话提示；“换一批”仅浏览本地数据，离线可用，不消耗 AI 额度。主应用点击复制，再回聊天窗口粘贴。接话提示应在对方回答后按实际情况选用。

安卓键盘点“AI/话题 → 找话题”，下拉选择分类，点击开场白直接填入当前输入框。点击“怎么接着聊”查看后续一句，可返回话题库；结果区上下滚动浏览。输入框为密码、数字、邮件、网址或禁止个性化时停用话题与 AI。返回打字、切换模式、人设或输入框会取消旧请求，过期结果不会填入新输入框。

“AI 找话题”复用后台已有模型地址和密钥，按当前人设、关系和场景生成 1–3 条自然开场白，实际数量由套餐决定。无需对方先发消息；可主动粘贴或选中最多 200 字背景。AI 与回复共用每日额度，不自动重试，也不会自动读取聊天记录或自动发送消息。后台暂不可用时仍可浏览离线话题。

数据源是 src/data/topics.json，修改后运行 npm run data:topics，同步 Android/iOS 资源，再运行 npm test。topicsUi instrumentation 验证离线浏览、开场白/接话填入、换一批、缺配置提示、真实 AI 话题预览/填入、输入框隔离和密码禁用。此模式会主动请求一次真实 AI。iPhone 主应用与扩展已同步工程，结构检查不能替代 Mac/Xcode 编译。


## 界面与体验（1.7.0）

底部固定提供回复、话题、人设、记录、键盘五个入口，输入时隐藏导航以保留编辑空间。统一配色、字号、间距、圆角与加载/空白/错误状态；主应用常用操作至少 48 dp，正文与主操作文字按 4.5:1 对比度检查。字母键保留适合输入法的紧凑布局，不能据此宣称所有键均为 48 dp。

话题页支持本机收藏；记录页可按原消息或回复搜索、查看、再次复制和删除。新生成的每条候选单独保存，事务失败会整体回滚；保存失败仍可复制已生成的回复。旧记录继续可读，不自动删除或改写。收藏、人设和常用词均不自动跨设备同步。

主应用与安卓 AI 面板都支持主动取消。更改消息或参数会丢弃旧候选；主应用粘贴新消息后也会清除旧回复。安卓键盘在生成中清空或更换来源会取消旧请求，取消 AI 话题后仍能浏览离线话题。结果和错误会主动滚入主应用可视区域。不自动重试收费请求，网络或上游失败后由用户手动重试。

验证：npm run check、npm test、node --test tests/ios-project.test.cjs；Android lintRelease；真实 Android 编辑器的 candidateUi、stabilityUi、polishUi 与 hostUi。polishUi 使用本地 HTTP 响应验证取消与旧结果隔离，不产生供应商费用；hostUi 主动调用一次真实 AI，验证回复、记录、搜索和复制。原生 instrumentation 结束后系统会终止被测应用，应重新打开主应用并让测试编辑器获得焦点后再继续测试。

## 日常使用衔接（1.8.0）

安卓主应用与键盘共用话题收藏；原 AsyncStorage 收藏首次读取时与原生新收藏合并，只迁移一次。后续按 ID 修改，不用旧快照覆盖新收藏；损坏列表恢复为空且只接收当前话题库中的 ID。iOS 继续使用主应用本机收藏。

键盘页显示系统启用/当前选中状态，返回前台自动刷新；试打区不发起 AI 或保存聊天记录。使用帮助提供常见问题、实际联网数据流、版本及复制反馈模板。当前仍为 HTTP IP 内测。

新增 sectionsUi instrumentation（21 项）验证双向收藏、恢复刷新、原生收藏插入但不发送、试打/帮助返回与状态刷新；不调用付费 AI。可加 -e captureSections true 保存测试 UI 截图到模拟器的应用 external files 目录。测试 APK 只安装到模拟器，禁止发布。


## 使用中心（1.9.0）

键盘页加入额度与套餐、备份恢复、更新中心。额度 GET /api/aikeyboard/account 使用现有 app/device 认证，规则与实际生成共用；套餐未上架/支付未接入时如实显示。成功回复与 AI 话题统一写入安卓 GenerationStore SQLite；主应用旧记录一次性事务迁移，按用户消息分组保留全部候选。清空不复活旧副本，记录保存开关对两端生效；iOS 继续使用主应用 SQLite。

备份使用 SAF 文件选择器与 AES-256-GCM/PBKDF2-HMAC-SHA256（120000 次），含记录及白名单设置，排除连接码、设备身份、供应商密钥、订阅/额度和保存开关。恢复先预览再合并，UUID 去重、人设冲突生成确定性副本，SQLite 事务/偏好日志处理失败与中断。上限 10000 条记录和 16MB 明文，词库/人设合并超限拒绝整次恢复。Android 自动云备份及设备迁移通过 manifest 与 extraction rules 排除。

更新清单来自服务器根目录 /downloads/chatq-android-latest.json，字段 schema/version/versionCode/sizeBytes/sha256/url/publishedAt/notes。下载 URL 必须同源 /downloads/*.apk，HTTP 仅用于既有内测 IP/本机；拒绝跳转，验证 SHA256、包名/版本与现有签名，FileProvider 只向系统安装器授权读取。本人授权安装来源后返回继续，不自动安装。发版需同步 app.config.js、package.json 与 UpdatePanel 的 CURRENT；发布清单最后原子替换，旧发布文件不可覆盖。

## AI 对话流式体验（1.11.0）

对话模式在原多轮/人设功能上增加 SSE 实时回复、最后回答重新生成、会话全文搜索。Android ChatStream 仅为显式开始的单次请求保留最多 10000 字内存预览；JS 在请求活动时读取该缓冲，终止后释放，不轮询剪贴板或其他应用。原生网络总时限 75 秒，行/帧最多 65536 字符、总计 1048576 字符上限。终态 done 必须与已显示片段一致；EOF/错误不能保存为完整回答。

POST /api/aikeyboard/chat/stream 复用受保护 conversation.send、同一用户事务额度、requestId 和取消信号；增量为 data:{type:delta,text}，事务成功提交后才发 {type:done,reply,usage}，已开始时的失败为 {type:error,message}。OpenAI 兼容上游 JSON 仍接受，且不二次调用；流式失败不尝试其他供应商。

重新生成使用最后一轮原问题、此前轮次、当前人设和背景。成功原位替换，保留轮次 ID、数量和输入草稿，失败或停止保留旧答案。未完成预览永不入库或作为上下文。搜索 query 最长 200 字，扫描本机最多 50 段完整会话，按字面忽略大小写匹配标题/背景/草稿/全部问答/人设名，返回匹配片段，不请求服务端。

测试 streamChecks 使用生产 Kotlin 类与本机 socket 拆包、断流和取消；conversationChecks 增加全部字段搜索；chatUi 用合成 SSE 回答检查真实流式、重新生成、草稿、搜索、停止和 IME 布局，不调用付费模型。iOS 源版本同步，缺少原生流式桥时沿用一次 JSON 请求；未声称 iOS 已编译或支持原生流式。

## 1.14.0 增补

对话使用原生安全 Markdown 排版（不执行 HTML、不加载远程图片），代码块可单独复制，外链确认后打开。重新生成保留最近4个成功回答，可比较和切换；设置中的分支列表展示编辑来源，原会话删除不影响分支使用。
