# 安卓聊天工作区 · 1.32.0

聊商帮助用户输入、润色并选择适合当前对话的回复。界面采用清楚、克制、亲切的方向，视觉来自编辑区、对话正文和键帽。回复正文与当前可执行操作优先呈现，偏好选择集中于可滚动面板。

首页减少常驻设置区。消息编辑框增高，人设入口、紧凑条数选择和固定生成操作靠近编辑内容。详细人设、关系、语气、背景与草稿控制集中到回复偏好面板，顶部保留完成入口，系统返回键可关闭。进入后台或切换页面也会关闭面板。

回复页保留复制作为主要动作，收藏、表情和改写使用紧凑的辅助操作。主生成按钮填满底部操作区域，便于拇指触达。键盘生成成功后折叠重复状态行，为回复正文留出空间，失败、取消及配置变化提示继续显示。再次生成使用辅助按钮层次。

设计参考了 [RikkaHub](https://github.com/rikkahub/rikkahub) 的内容排版与设置分组、[HeroUI Native](https://github.com/heroui-inc/heroui-native) 的选择面板组织，以及 [Fcitx5 Android](https://github.com/fcitx5-android/fcitx5-android) 的键区层次。实现沿用聊商现有 React Native 和原生 Android 组件。

按间距、颜色、图标、文案、字号、布局、交互状态、视觉和动效顺序审核。间距使用 4/8/12/16 的节奏，灰白表面与品牌紫形成层级，系统字体和文字换行适应字号设置，主要触控入口至少 48dp。正文、当前输入状态与明确反馈承担视觉重点，面板使用原有进入与关闭动效。
