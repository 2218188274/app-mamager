# 两端配色与状态层次 · Android 1.33.0 / Windows 0.8.2

产品：帮助用户顺畅打字、润色和选择回复。
性格：沉稳、清楚、亲切。
视觉来源：文字编辑区、对话卡片和键帽。
重点：回复正文及当前可执行动作；主色只强调选择和操作。
识别细节：鸢尾蓝选中边界与清晰的键盘焦点。

## 颜色规则

| 用途 | 色值 |
| --- | --- |
| 页面 / 内容 | #F6F7FA / #FFFFFF |
| 次级区域 / 卡片边界 | #EEF0F5 / #D8DDE8 |
| 正文 / 次级文字 / 辅助文字 | #202536 / #4D566D / #5F697E |
| 主操作 / 按下 | #4F55A7 / #42488F |
| 选中区域 | #ECECF9，配主色文字或边界 |
| 输入边界 | #8792A8，聚焦使用主色 |
| 错误 / 成功 | #B4233C / #25634A |

主应用和输入法使用同一角色命名。原生安卓键盘的暗色主题采用深蓝灰表面、浅色文字及浅鸢尾蓝选中提示，主要操作仍使用深色填充配白字。文字、边框和背景分别承担内容、交互边界和分组职责。

输入、回复、设置和候选区均采用纯色；渐变不用于文字背景、键帽或状态，以免影响对比和误判选中。表情内容保留其自身颜色。保留已有品牌图标和系统字体，不新增装饰图片、光晕或动画。

按间距、颜色、图标、文案、字号、布局、细节、视觉及动效顺序审核。沿用4/8/12/16节奏、至少48dp安卓入口、WPF44DIP操作和字号换行。选中状态同时具备色块与边界或标签，不仅依赖颜色。

修复安卓原生高亮键按下后白字落在浅色底上的对比问题。测试真实发货Drawable的普通/按下状态，覆盖明暗主题；主应用文字对比至少4.5:1，输入边界至少3:1。小屏与200%字号回归只使用合成数据和本机接口，不能替代真实微信/QQ兼容验收。
