# 会员与订单交互

沿用紫色品牌、浅底卡片、16dp 外边距与卡内分组。购买金额和期限优先；次要信息用说明文字，账户入口保持在会员页上方。所有主要操作至少 48dp。

订单页使用安全区，标题与返回按钮允许换行；金额、状态、日期分层。正文 15/24、说明 13/21、标题 17/25，金额 23/32；跟随系统字体，不限制大字号缩放。200% 字号时主要操作文字自然换行，内容可滚动，返回固定在顶部。

购前展示账号绑定、金额、天数、非自动续费；首次确认创建订单，第二次确认打开指定来源收银台。返回应用自动查询该原订单，仍未确认则保留手动查单。禁止隐式重下单和把过期入口当作支付失败。

已到账移除收银台按钮。订单号复制使用网关商户订单号；过期、退款与权益冲突均有明确状态和下一步操作。商户未就绪时如实显示，不使用演示价格冒充已上架套餐。

按亲密性归组套餐/订单，按对齐保持统一边距，按重复统一卡片/按钮/字号，按对比分清金额、状态、主按钮与说明。320dp × 640dp、100% / 200% 字号均通过模拟器购买与到账流程，具体结果见发布验证文档。
