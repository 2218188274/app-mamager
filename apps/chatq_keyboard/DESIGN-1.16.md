# 聊商 1.16 · 粘贴、润色与返回打字

沿用 [1.15 布局规范](DESIGN-1.15.md)，本轮只收敛安卓键盘的高频路径。主应用生成记录识别新增的“润色”类型。

## 三条主路径

- 帮我回复：复制对方消息 → AI 助手 → 粘贴并生成 → 点选结果，立即回到打字。已有原文时“重新生成”使用原文，“粘贴生成”处理新复制的消息。
- 润色我的话：点“润色输入框”主动读取当前草稿；有选择范围时只处理选中部分，没有选择时处理整段。也可“粘贴润色”。原文保持不动，点选结果后才替换或填入。
- 返回打字：AI、表情、编辑、设置、非数字字段的数字页与展开候选页都有固定返回路径。返回时停止尚未完成的 AI 请求；展开候选页返回时保留未完成的拼音。填入回复、润色或话题后自动返回原来的全键盘/九宫格。

人设、语气、数量、记录、重新读取原文收在 AI 工具栏“偏好”。主面板只呈现帮我回复、润色我的话、找话题三个任务。

## 保护原文与可恢复操作

1. 不自动读剪贴板，不解析剪贴板 URI，只读取用户本次点击粘贴的纯文字。空白、非文字、超限内容不会清掉已有原文，也不静默截断后上传。
2. 原文上限为 1000 字；话题背景为 200 字。切换任务分别保留各自原文，切换编辑框会清除临时内容。
3. 生成失败、停止或返回打字后，仍可使用原文重新生成。不会自动重试或自动发送消息。
4. 润色替换前再次比对当前输入框文字和选择位置。输入内容或光标已变化时不覆盖；重新读取并润色后再选择。编辑器不支持完整读取时提示复制原文，不能猜测替换范围。
5. 重新打开 AI 面板时，保留的候选仍可点选，不能留下看得见却失效的操作。
6. 隐私、密码、数字等禁用 AI 的编辑框不会读取或上传内容。返回、取消和任务切换使旧请求失效，迟到的响应不能重新填入或显示。

读取使用 Android 的 [InputConnection](https://developer.android.com/reference/android/view/inputmethod/InputConnection) 与 [ExtractedText](https://developer.android.com/reference/android/view/inputmethod/ExtractedText)；仅在能确认完整片段和合法选择范围时提供替换。系统 API 可能不被第三方编辑器完整支持，真机兼容性仍需单独验收。

## 服务与兼容性

润色使用独立的 `polish` 任务类型，模型指令要求保留原意、人称、事实、数字、时间和承诺，不把原文当成对方消息作答。它沿用回复的鉴权、禁用用户检查、额度、取消与计数路径。未传任务类型的旧客户端保持回复行为。模型输出仍需用户检查，指令不能保证所有模型始终准确。

安卓生成记录、搜索、加密备份接受“润色”记录；主应用显示“我的原文”和“AI 润色”。旧版客户端不认识新记录类型，备份请在 1.16 或更新版本恢复。

## 发布验收边界

以本轮 `artifacts/ChatQ-1.16.0-flow-validation.md` 为实际结果。模拟器采用独立的合成输入框和本地 HTTP 服务；不读取微信/QQ消息，不发送聊天消息，不调用收费模型。模拟器通过不能称为微信/QQ真机通过。

商用验收尚需主流手机、第三方输入框、Android 16、TalkBack、横屏/长期输入测试、正式签名、HTTPS与服务器容量、支付实单与退款对账、运营协议审定。此次保持内测升级证书和现有数据。
