# 聊商 Windows 0.7.2

Windows 10/11 x64 桌面 AI 助手与原生 TSF 拼音输入法。免费、自备 API；会员购买与正式收款关闭。API 生成直连所配置的供应商。

## 安装与配置

安装包选择“桌面助手和系统输入法”，再按 Win+空格切换到聊商拼音。便携包只提供桌面助手，不注册系统输入法。Windows 仍为未正式签名的预览版。

在“我的 API”填写接口、密钥和模型并保存。密钥使用本机 Windows 账号加密，不应填写在公开文件、截图或聊天中。供应商额度及收费由其自身规则决定。模型列表成功不代表生成权限已通过；连接测试需要主动触发，不自动重试。

## 输入法内快捷回复

点击候选框“AI 回复”、右键中英状态，或按 Ctrl+Shift+空格打开面板。复制消息后选择“粘贴生成”，选中自己的话可“选中润色”。回复沿用保存的 API、人设和条数。选择“复制”或“填入”使用结果，Esc或返回继续打字；填入不会按回车或发送。

Tab / Shift+Tab选择可用操作，Enter或空格确认，初始焦点在返回。左右键切换回复，上下键、PageUp/PageDown、Home/End阅读正文。生成时可以选择停止。长按确认键或打开面板的空格后，其重复和松开事件仍绑定原输入框，避免串到宿主编辑器。

面板不会激活另一个窗口，普通打字、输入框/焦点/光标变化会清理旧结果。复制和填入前再次核对配置及选区。200%文字使用更高面板；短窗口收紧状态并折叠来源预览，保留正文和底部操作。完整屏幕阅读器UIA仍待完善。

只在主动粘贴或润色时读取对应来源，不读取周边聊天或轮询剪贴板。隐藏生成进程采用匿名管道，提示词不放入命令行或文件，输入法内生成不自动保存历史。

## 日常拼音

支持离线全拼、常用简拼、分段选词及常用词组。空格和1–5选择候选，左右键选择，PageUp/PageDown翻页，退格删除拼音，Esc取消，Enter确认原拼音。单按Shift或Ctrl+空格切换中英，组合快捷键沿用编辑器行为。中文标点可在无待输入拼音时直接输入。

## 主应用

提供多轮 AI 对话、人设、回复润色、截图辅助、草稿、生成记录、收藏、资料分析、备份恢复及手动更新检查。截图和语音只在主动操作后处理；真实视觉模型、麦克风和设备行为需要独立验收。

聊天导入处理主动选择的JSON/CSV/ZIP文件；数据库导出只接受已解密、关闭的独立副本，不获取密钥、不读取实时库、不执行第三方导出程序。分析先选身份、范围和问题，再检查外发预览。原文默认不保存，资料库保存与分析结果保存分别主动触发。

资料库、分段分析进度和普通配置备份各有独立格式与容量限制。恢复前预览，取消或失败保留旧文件。Windows/Android手动加密互通只迁移人设文本、收藏句和AI对话主线，API与连接凭据不随此格式迁移。

## 验证与边界

开发回归只使用合成文本、本机模拟接口和不可见WPF检查。注册TSF、双架构及安装升级/卸载在一次性Windows虚拟机验证；不在用户电脑伪造CI标志运行。合成结果不代替真实软件输入、硬件、双设备迁移或外部连接验收。

消息适配器属于独立配置和验收模块，不能据模拟接口声称持续无人值守可用。正式签名、完整读屏、真实软件与硬件兼容需分别验收。维护公开文档时只记录产品能力和合成验证，不发布个人账号活动或测试授权历史。
