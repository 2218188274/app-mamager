# 聊商 Windows 0.5.2

Windows 10/11 x64 的桌面 AI 助手与原生 TSF 拼音输入法首版。当前免费、自备 API；不启用会员购买和正式收款。API 生成直连用户供应商。

## 0.5.2 消息助手连接隔离修复

修复暂停后重新连接时，旧连接迟到的成功、失败、断开或消息回调影响新连接的问题。连接启动固定使用本次账号/好友配置快照，仅本次连接成功才能显示就绪；旧回调不能触发当前账号的AI生成，也不能误停正在建立或已经就绪的新连接。连接期间配置变化则拒绝就绪。

修复旧连接中的发送迟到失败，误暂停新连接中同一好友规则的问题。仅发送所属连接、配置和账号/好友目标仍一致时，未知结果才暂停该好友；旧结果保留为历史未确认记录，不重试、不加入新上下文。旧记录已由用户清理时，迟到结果不会导致新连接停止。数据格式不变。

回归使用故意忽略取消、延迟启动和延迟发送的合成连接器；没有真实聊天、外部组件或收费AI调用。仍需用户自备授权连接组件和真实软件验收，不代表已经打通微信/QQ个人账号。

## 0.5.1 微信连接准备修复

2026-11-04核对[官方安装文档](https://docs.wxauto.org/docs/install.html)：Plus列出Python3.9–3.13与微信4.1环境，当前使用的`AddListenChat`属于Plus接口，不能直接用免费`wxauto4`替换。文档不代表已验证微信4.2；不要自动降级或改动现有客户端。当前只推进修复和配置，未安装/激活或连接真实账号。

准备检查修复Python3.14即使存在安装信息也被显示可用的问题。真正建立微信连接前再检查所选解释器及包元数据；缺包或超出文档范围时，在加载第三方模块前阻止。检查仍为`-I -S`标准库读取元数据，不执行`.pth`、不调用AI、不连接微信。

微信连接页新增折叠准备步骤，授权和真实客户端验收单独列为待确认。适配器在创建微信实例前设置`WxParam.ENABLE_FILE_LOGGER=False`，无法关闭则拒绝初始化；实际第三方模块导入行为仍待授权环境验收。[官方参数/响应文档](https://docs.wxauto.org/docs/class/Other.html)说明文件日志参数和`WxResponse`布尔判断；若可取得实际响应类型，发送回执使用该类型的布尔语义，其他任意真值对象/字典不算提交成功。

失败提示按缺依赖、初始化/授权或客户端问题、账号不符、好友窗口变化、草稿保护、未确认提交分类。启动失败的固定原因不再被中断回调抢先掩盖；运行中只接受已知固定提示，不显示外部原始异常。空回执、错误nonce、畸形或越界帧停止处理，未知发送不重试。好友窗口变化即停止适配器接收并清除待发送目标。真实收发、账号和输入框内部属性兼容仍未验收。

## 0.5.0 聊天导入与分析

新增独立「聊天分析」入口，接收用户主动选择的微信聊天导出文件：

1. 选择 `messages.json`、`messages.csv`，或结构化读取包 `messages/` 目录中的单个JSON；也支持只含消息数据的ZIP。不会运行导出程序、加载密钥DLL、解密/扫描微信数据库或跟随manifest中的磁盘路径。安装包ZIP会被拒绝。
2. 选择一个会话，主动确认「哪位是我」。JSON可选择使用逐条`IsSelf`标记；无标记的CSV须手动选发送人。按最近50/100/200条文本分析，支持1–10条建议；受上下文上限影响时明确展示实际条数和长消息缩短情况。可识别时间的会话按时间排序，否则提示沿用导出顺序。
3. 核对化名摘录、当前API目标和实际发送范围，勾选允许后点击生成。发送人用我/对方代称，并替换已知称呼、手机号与邮箱；不能保证识别所有隐私，须核对预览。AI直连当前自备API，不经聊商平台；导入本身不调用AI。
4. 结果包括聊天总结、附有效消息编号的观察、下一步行动、延续话题和回复卡片。可复制、继续润色或主动导出分析TXT；修改问题后重新分析可聚焦下一步怎么聊。未知引用或不完整结果拒绝采用；切换范围、身份、问题、条数或API会取消/失效旧请求。

导入原文及分析只在当前进程内暂存；不写入本机通用会话、消息助手、云端或备份，也不会自动回复好友。退出需重新导入；明文分析TXT只在用户主动保存时生成，原导出文件不修改。媒体只统计占位、不读取或理解图片/语音。当前不支持长期导入库、全文分段总结、OCR补全或跨设备同步。

兼容依据来自用户提供安装包的静态字段：`ExportPayload.Session/Messages`、`AgentMessage`（Id/ServerId/Talker/Sender/IsSelf/Type/Time/Content）及中文CSV列「时间,发送人,类型,内容」。包内Go模块标识为`github.com/piperTang/chatlog_alpha`，自定义WPF界面为`WxKeyCaptureTest`；本项目未执行或再分发这些组件，未验证其真实导出或当前微信兼容。导入回归仅使用合成的对应格式，真实文件由用户后续验收。

## 当前范围与0.4.1连接准备

当前仅推进 Windows 与安卓，先 Windows；iOS 工程和归档仅保留为历史资料，不继续主动开发、构建或验收。

消息助手首次打开显示三步准备清单：保存自己的API、账号/连接、指定好友。配置不全时连接按钮禁用，并可直接前往相应设置。保存与检查按钮固定在可见底部；连接成功但还没有消息时明确显示等待状态。

“检查连接准备”只检查当前填写的配置，不调用模型、不登录聊天账号。QQ只建立一次本机TCP连接确认端口是否响应，不发送访问令牌、OneBot请求或聊天消息；端口可达不能证明服务协议、本人账号或发送能力。微信使用所选Python的 `-I -S` 隔离模式，仅通过标准库读取wxautox4安装元数据，不加载该模块，不执行sitecustomize或.pth启动代码，也不验证激活或微信4.2等实际客户端兼容。改变表单会使旧检查结果失效。

修复连接配置保存后清空密码框、再次保存可能回写旧令牌的问题；空白令牌仅从最新保存且账号/地址相同的配置中沿用，换地址或账号必须重填。拒绝本机端口0。通用数据格式和消息队列格式均不变化。

## 0.4.0 消息助手（连接适配预览）

面向用户本人账号的指定好友私聊，提供「生成后确认发送」和逐好友明确启用的「自动回复」。每位好友分别选择 API 与人设、分别保留最近20条已确认提交的上下文。打开软件始终暂停，不自启动连接，也不自动重新连接或补发。

1. 我的 API：保存用户自己的兼容 API；消息助手生成使用非流式完整回答，不把半条回答发给好友。
2. 消息助手 → 连接与额度：QQ填写本人号码、本机 OneBot11 混合 WebSocket 地址 `ws://127.0.0.1:端口/` 和至少16位令牌；微信选择已安装并有权使用 wxautox4 的 Python.exe，填写当前微信显示名称。
3. 指定好友：QQ填写准确好友号码；微信填写唯一好友备注名。接收对象绑定后不可改，换人请另建规则。先用默认确认模式；自动模式需要单独确认。
4. 主动连接：核对本人账号、指定好友、调用额度和自动规则，再处理连接后收到的新文本。连接会调用自备 API，费用由供应商计收。按 UTC 日重置的生成/发送尝试上限默认各20次，同一好友生成间隔默认30秒，失败也占尝试次数。
5. 待处理消息：核对原消息，编辑回复再确认。确认发送与人工接管固定可见；在其他页面仍有运行/暂停入口。新消息使旧回复失效，收到可识别的本人手动消息会暂停对应会话；也可随时人工接管。退出或锁屏暂停。

**外部组件与实际验收限制：**

- QQ 是独立编写的 OneBot11 正向 WebSocket 客户端，只允许本机 `/` 混合接口，鉴权握手不跟随跳转、不用 Cookie/代理，校验登录号；出站纯文本与原好友号码绑定。用户须另行准备有权使用的桥接组件，聊商未附带、安装或启动 NapCat/QQ协议实现。连接组件的授权和客户端限制须另行核对。
- 微信是独立 stdio 适配器，仅在用户点连接后启动自选 Python；wxautox4及其激活/商业授权均不附带或自动安装。需能读取本人昵称、准确绑定好友子窗口并检测输入框为空；能力缺失、窗口不符、有未发送草稿时拒绝发送。不支持的依赖版本可能无法连接或发送，不能将本预览描述成已适配所有微信版本。
- 微信界面自动化无法提供与官方消息 API 相同的身份与原子性保证；显示名/备注名变更、同名联系人、输入框控件变化、窗口关闭/最小化、用户并行操作都需要在实际客户端验收。首次先确认模式，不承诺后台无人值守兼容。
- 当前只处理指定好友的纯文本私聊；群聊、图片/语音代回复、离线补历史及自动重连未开放。未监听的好友不进入模型和本机消息记录。不读取历史 API、不轮询剪贴板、不登录替代机器人身份。
- 转人工词默认包含验证码、转账、付款、密码，原消息或回复命中时留在确认队列。词匹配只是路由规则，不能保证识别所有敏感语义。模型没有工具执行权限。
- 发送前落盘预留。组件确认仅表示提交，不代表对方收到；失败/超时/未知结果暂停该好友，不提供自动重试。旧连接的迟到回执不写入新会话上下文。客户端是否上报本人发送事件影响自动接管检测，手动「人工接管」始终可用。
- 消息与连接令牌使用独立 `messages.vault` 由当前 Windows 账号 DPAPI 加密，原子写入并保留 `.bak`；队列最多80条，待确认/未知记录满时暂停而不静默覆盖。通用 `.cqb` 备份暂不包含此文件、代回复上下文或连接配置；卸载仍保留文件。清空记录保留去重标识与当日额度，不能用重新连接刷新额度。

验证仅用合成好友、临时加密数据、localhost模型与本机假 WebSocket 服务，不导入 wxautox4、不运行真实微信/QQ、不读取真实聊天或发送真实消息。实际平台连接与兼容验收仍按用户安排暂缓；本版本仍未正式签名。

## 0.3.0 更新

- 输入框的“添加内容”集中提供截图辅助回复、语音转文字、表情入口。
- 截图支持主动选图或粘贴、裁剪、不可逆像素遮挡、气泡左右识别、文字核对后追加。需要当前模型支持图片理解；图像仅在内存中处理，不进入记录或备份。
- 语音支持用户手动录音（0.2–120秒）或导入16位PCM WAV，确认后通过自备 API 转写。语音模型在“我的API→语音转写设置”填写，需要供应商支持 `/audio/transcriptions`。硬件录音与真实供应商质量未验收。
- 表情页含6张原创云朵图片、30个Emoji/颜文字，支持20张自定义PNG/JPEG缩略图、收藏、主动复制和PNG导出。不自动发消息，具体软件粘贴行为仍待验收。
- 记录收藏保存100条已完成候选，支持搜索、收藏、复制、继续润色；容量不足先淘汰非收藏，收藏满时保留原记录，仍展示本次生成结果。
- 数据与更新：密码加密 `.cqb` 备份、解密预览、合并或替换恢复、显式损坏文件恢复；API配置与密钥永不从该备份导入/导出。手动检查更新，不自动下载安装。
- 新客户端兼容原格式1，写入扩展格式2时保留独立的加密 `.v1-*.bak` 回滚文件。旧版会拒绝读取新格式，请用新版管理新增记录；卸载仍保留本机数据。

延续0.2.0的统一排版、窄窗口/200%字号、草稿恢复、编辑上一问和请求取消保护。本机可见窗口、真实聊天软件、麦克风和付费供应商仍按验收清单单独验证。测试只使用合成图片/WAV和localhost接口。

## 使用

运行完整版 Setup，按需选择桌面助手和输入法；系统输入法注册需要管理员确认。安装后打开聊商 → 我的 API → 保存供应商基础地址、密钥和模型。生成、测试连接和获取模型列表都由用户主动触发。

- 帮回复 / 润色 / 找话题、人设 / 关系 / 目标、1–10条回复；生成后主动复制再粘贴。
- AI 对话：本机多轮会话、流式回复、停止、重新生成、搜索、改名、删除和文本导出。
- 人设中心：内置人设、自定义编辑、AI 生成草稿后确认保存。
- Ctrl+Alt+Q 唤出助手（只在应用运行期间注册，冲突时提示）；不自动读取或轮询剪贴板，不自动发送消息。
- Win+空格选择“聊商拼音”；字母输入拼音，空格或1–5选词，Page Up/Down翻页，左右键切换候选；Esc取消、退格编辑、Enter确认原文，Ctrl+空格切换中英；系统输入模式入口显示“中/英”，支持点击切换，切换前保留尚未转换的拼音字母。候选栏 AI 按钮唤出同一个桌面助手并进入“帮回复”，保留之前的会话/润色草稿，API、人设与会话共用本机配置。
- API 密钥及本机会话/草稿使用 Windows DPAPI CurrentUser 加密；损坏时停止覆盖，保留加密备份。数据位于当前账号 LocalAppData/ChatQWindows，不因卸载自动删除。

便携版只运行桌面助手，不会自动注册系统输入法。卸载完整版仅移除本项目的 COM/TSF 注册，不改变其他输入法或删除本机用户数据。

## 构建与验证

要求 .NET10 SDK、Visual Studio2022 C++工具和Windows SDK、CMake、Python3、Inno Setup6。

```powershell
dotnet build Desktop/ChatQ.Desktop.csproj -c Release
python tests/run-fixture.py
cmake -S native -B out/native-x64 -A x64
cmake --build out/native-x64 --config Release
ctest --test-dir out/native-x64 -C Release --output-on-failure
```

GitHub Actions `ChatQ Windows build` 为手动构建，生成 x64/x86 输入法、包含运行时的 x64 助手和 Setup。测试使用实际 Windows DPAPI、本地合成 HTTP 模型、离线词典和实际 TSF 管理器/合成内存文档，不读取用户聊天，不进行付费 AI 调用，不注册全局默认输入法。

当前是未完成正式代码签名的预览版本。构建成功与合成 TSF 回归不能等同于完成安装、微信/QQ、浏览器、Office、UWP、管理员窗口或长期输入体验验收。候选屏幕阅读器集成、完整移动端数据互通、单手/九宫格等不属于本首版已验收范围；验收状态以交付报告为准。
