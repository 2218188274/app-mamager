# Windows 界面整理 · 0.8.0

本轮采用 light polish：保留既有导航、品牌紫、微软雅黑及功能结构，统一桌面助手和原生输入法面板。以内容和操作结果作为视觉重点。

## 设计方向

- 产品：让日常聊天输入和回复更省步骤。
- 性格：克制、清楚、亲切。
- 视觉来源：键盘、文字和对话卡片。
- 重点：当前回复正文清楚醒目，导航和辅助说明安静退后。
- 识别细节：一致的快捷键键帽、清晰的当前项和键盘焦点。

## 审核与修改

1. 间距：统一 4/8/12/16/20/24 DIP 节奏；扩大页面留白，明确卡片内边距和分组。原生面板正文保留独立内边距。
2. 颜色：灰白页面、白色内容、浅灰辅助表面；紫色集中于当前项、焦点及当前主要动作。正文 #23232B、辅助文字 #52525B；白底正文对比约 15:1，辅助文字约 7.7:1。紫底白字约 5.5:1。
3. 图标：保留现有系统图标，统一尺寸、对齐和次级色，移除空状态装饰星号；快捷键使用文字键帽。
4. 文案：空状态解释结果如何出现；本地资料工具不再提示配置 API；回复和分析入口继续保留必要配置提示。
5. 字号：保留字体，统一常规和 Medium 字重；按钮至少 44 DIP、文字可换行。修复大字号长按钮裁切。
6. 布局：保留页面顺序和响应式结构；修复宽屏人设卡片因取整误差变为单列的问题；200% 字号隐藏设置内重复标题，让自动开始控制保持可见。
7. 细节：统一按钮、边框、圆角、禁用状态、鼠标悬停和键盘焦点。原生面板仅在可用时强调填入；生成阶段和结果阶段分别突出主要动作。
8. 视觉：回复正文就是核心视觉。保留图标和品牌资产，不增加插画、营销图片或无用途装饰。
9. 动效：本轮不增加动画；保留直接反馈，减少输入操作中的干扰。

按对比、对齐、重复、亲密性复核小屏、200% 字号、触控范围、主次、返回、错误与禁用状态。合成图片用于排版审核，不代表真实聊天软件兼容或读屏验收。

## 验证与边界

回归覆盖长按钮换行、人设卡片宽屏双列及大字号单列、本地资料页提示、缺少 API 提示、自动开始控制的位置，以及现有生成、取消、资料保存等操作。主应用使用不可见 WPF 和本机模拟接口，原生 TSF 使用一次性 Windows 虚拟机的合成对象。结果以本版交付审查为准。

没有生成图片，无图片提示词或新增素材依赖。Windows 正式签名、真实宿主输入兼容、麦克风及双设备迁移仍需独立验收。
