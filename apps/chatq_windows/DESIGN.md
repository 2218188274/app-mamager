# Windows 界面规范 · 0.4.1

面向桌面日常操作，主应用与原生输入法入口共用本机配置。保持免费、自备 API。

- 对比：每个操作区保留一个紫色主要动作；删除操作收进展开区；请求进行中禁用重复提交，停止按钮只在可取消时启用。
- 对齐：宽窗口采用侧栏和双栏回复区；窄窗口、200%系统字号采用顶部导航和单栏。表单标签、输入框和卡片边缘对齐。
- 重复：统一紫色、浅色背景、14DIP基础字号、圆角、留白、图标和至少42DIP按钮；字段与卡片使用同一套组件。
- 亲密性：内容和解释放在同一卡片，主操作固定在可见底部；人设、关系、目标和条数收进偏好，会话管理集中在一个入口。

用户的系统字号优先。大字号模式移除重复的页面标题，为内容留出空间。短窗口可以滚动表单，主要提交按钮仍可见。表单密钥不显示在可复制的文本或提示中。

回复卡片提供复制与继续润色。会话支持连续对话、重新回答、编辑上一问、恢复未发送草稿；编辑失败或取消不覆盖旧回答。新增配置不能删除之前启用的配置，模型列表和连接测试使用当前填写的地址与密钥，只在用户点击时发起。

审核使用本地合成 API、临时加密数据和不可见 WPF 控件。排版图由 RenderTargetBitmap 输出，无窗口显示、输入注入或真实聊天读取。这些结果不代表已经完成微信、QQ或真实窗口交互验收。

消息助手分为待处理、指定好友、连接与额度三个版块；确认发送和人工接管固定可见，连接中或运行中仅显示暂停动作。其他页面显示运行与暂停入口。接收对象绑定后不可修改；外部依赖、实验适配和未确认提交须明确提示。大字号原消息可展开，回复可编辑，后台新消息不能覆盖正在核对的草稿。

首次连接采用三步准备清单与固定下一步入口。设置页固定保存与检查动作，检查结果与真实收发验收分开展示；未完成配置不能连接，表单修改清除旧检查结果。
