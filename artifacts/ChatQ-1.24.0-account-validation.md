# 聊商 1.24.0 验证

日期：2026-10-26。只处理聊商及已授权检查的 Jeepay 候选环境；无真实扣款、收费 AI 调用、聊天内容读取或消息发送。

- 客户端 TypeScript 检查通过，144 项回归通过。覆盖迟到登录、清除登录、并发账号操作、凭据损坏、恢复码保存失败、过期登录及会员同步失败。
- 服务端 TypeScript 构建通过，68 项回归通过；恢复码重置的 REST 路由经过保护，并禁止缓存一次性响应。
- 隔离 PostgreSQL：57 项订单/回调/会员检查，39 项注册/登录/改密/恢复/恢复码重置检查；包括当前密码输错时保持有效登录。所有写入使用单连接 TEMP 表，未写生产业务表。
- Jeepay 宿主预检脚本通过 6 项 Python 测试；只读检查候选清单、私有文件权限、依赖健康、磁盘和容器状态，不回显密钥、不启动候选服务。
- Android 11 模拟器 320×640 mdpi，100% 和 200% 字号分别通过 66 项账号/恢复/会员 UI 检查、27 项订单 UI 检查。账户、金额、订单、回调均为回环夹具；不是正式实付。
- 实际应用界面覆盖注册密码不一致、恢复码确认保存、加密凭据、密码修改、恢复码轮换、退出登录、登录错误、找回保留账号、无效恢复码本地拦截、令牌失效重新登录、会员到期回落到免费额度。
- 订单界面覆盖到账后刷新、原订单重查、已到账主动核对退款、禁止重复下单、退款待核对及 48dp 按钮。已查看 200% 字号截图，见 artifacts/ui-1.24.0。
- ARM64 APK 1.24.0 / versionCode35，延续原内测签名。签名、16KB 对齐、ABI 和版本校验通过；两个 DEX、Hermes 业务包、expressions.json 与实际测试的 x86_64 包完全相同。

发布以同前缀 api-deployment.json、deployment.json 和 source.json 为准。部署前保存数据库备份、旧镜像/配置，核对用户/会员/额度/订单/套餐数据摘要；只替换聊商 API，保留数据库和语音容器、私有配置、旧安装包和回滚资料。

正式收款保持关闭：尚无正式商户、通道验收和上架价格。旧 Jeepay 是停止的隔离候选环境；缺少完整依赖健康检查，系统盘容量也不足以直接启动整套服务。本轮修复 ChatQ 接入、退款核对和配置预检，不将候选环境描述为可正式收款。

实体手机微信/QQ 验收按用户安排稍后执行，本次仅模拟器；短信/邮箱找回未接入。账号恢复依赖账号及恢复码，无恢复码需管理员核验。自动退款发起、退款权益扣减、跨档补差价和正式商店签名仍待独立实现/验收。
