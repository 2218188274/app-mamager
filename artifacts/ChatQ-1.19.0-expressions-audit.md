# 1.19.0 主应用与表情中心

## 布局与操作

参考已留存的 LoveKey、爱语 AI、LoveAI 官方宣传截图中的快捷入口、风格卡片、独立回复卡片结构；未复制竞品人物、商标或表情素材。参考样本和来源见 `artifacts/ChatQ-competitor-review-2026-10-24.json`，宣传图并不等于已安装竞品的完整体验。

- 首页：轻量标题，四个常用入口（人设、表情、话题、常用句），回复/润色双模式，输入与当前人设组成一个区域；生成按钮固定在底部导航上方。
- 大字号与矮屏：120%及以上字号或可用窗口高度不足560dp时将快捷入口收回发现页；200%字号隐藏装饰标题，将“回复”“润色”缩为短标签；功能仍能从发现进入。字体不锁定缩放，触控区域至少 48dp。
- 回复结果：原消息收为摘要，修改可展开；风格条、正文、收藏/加表情/改一改、全宽复制依次排列。默认滚动到新结果，复制有明确反馈。
- 人设中心：普通字号双列，130%及以上单列。颜色区分类型，示例只保留两行，管理操作收进卡片右上角 48dp 更多入口；当前人设和常用标记保留。
- 图标沿用代码绘制的线性图标体系，补齐表情、编辑、复制、收藏和搜索图标。淡紫主色搭配桃粉、浅绿、浅蓝辅助色，正文保持足够对比度。

## 表情与润色

内置 32 个 Emoji、8 个颜文字，按开心/关心/心情/日常/颜文字分类，可按中文含义检索。主动点击才复制；回复卡片加表情直接更新本条，可恢复上一版，不发起 AI 请求。

“软软云”首包包含你好、抱抱、谢谢三张原创静态透明 PNG，由 imagegen 为本项目制作，原始素材保留在模块 assets/stickers。点击预览后再点分享，安卓通过 ACTION_SEND + 系统 chooser + 私有 FileProvider 临时只读 URI 分享 512px 图片。仅允许三个内置 ID，不接受任意文件路径，不请求存储权限，不替用户选择聊天对象或发送。图片分享遵循 [Android Sharesheet](https://developer.android.com/develop/ui/compose/sharing/send) 与 [FileProvider](https://developer.android.com/reference/androidx/core/content/FileProvider) 文档。

图片表情首版面向安卓；iOS 工程保留文字表情，图片分享展示平台限制。图片能否被目标应用保存为自定义表情需在该应用实机确认，当前不宣称可直接注入微信或 QQ 表情栏。

回复和润色分别保存本次打开期间的草稿。润色请求明确 purpose=polish，保留原意；切换模式不误用对方消息作为自己的草稿。关闭应用后的草稿持久化尚未包含在本轮。

## 审核中修复

- 主应用粘贴空文字会清空草稿、长文字会静默截断：现在保留原稿并提示。
- 图片缩放浮点向下取整可能得到 511px：改为取整，逐张检验 512px 长边和透明通道。
- 130%字号下首屏快捷入口挤压输入框：按字号和可用高度收起次要入口。
- 大字号双模式标签拥挤：使用短标签与可收缩文本，完整读屏名称保留。
- 原回复错误提示引用“上方按钮”：改为符合实际位置的底部按钮。

测试使用 Android 11 模拟器、合成输入及本地 HTTP 服务，未读取真实聊天或调用收费 AI。详细结果以对应 validation.md 为准。仍需安卓新系统、TalkBack 和微信/QQ 真机验收；本次不等于完整商用认证。
