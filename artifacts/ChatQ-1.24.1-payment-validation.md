# 聊商 1.24.1 支付管理与 Jeepay 检查

本轮为管理后台和服务端更新。安卓继续使用 1.24.0/code 35，不更换已发布安装包。正式收款仍关闭；没有生成真实订单、发起扣款、退款或调用收费 AI。

## 完成内容

- 用真实 Jeepay 管理页面替换原支付配置占位表单，支持准备状态、商户配置、订单检索和原订单核对。
- 仅超级管理员可保存商户资料；要求 HTTPS、私有可写目录、销售关闭。历史订单绑定不可直接覆盖，旧配置私有备份、版本冲突检查和独占写锁防止相互覆盖。
- 页面不回显签名密钥；关闭 tRPC 请求输入日志，提交成功清除密钥及 mutation 引用。
- 修复套餐跳转丢失应用上下文。后台窄屏固定侧栏原本把表单挤成竖列，现可展开/收起，表单和订单区域重新排版。
- Jeepay 增量健康检查涵盖 MySQL、Valkey、RocketMQ namesrv/broker、支付查询处理器。消息队列探针用 64 MB 独立 Java 堆，避免默认工具 1 GB 堆占用。
- 原停用环境复制到授权数据盘，保留原数据、配置与容器。独立克隆网络禁止外网且没有发布端口，五项核心服务实际达到 healthy 后停止克隆释放内存。增量健康检查文件保存在原候选目录，原 compose 未改。
- 聊商旧静态发布目录完整迁至数据盘，校验 751 项、774531755 字节内容及属主权限，原路径通过原子交换保留为符号链接。安装包、更新清单和回滚历史保留，系统盘空闲从 413061120 提升到 1189752832 字节（迁移时测量）。
