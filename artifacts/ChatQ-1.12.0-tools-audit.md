# 1.12.0 交付审计

范围：会话重命名、历史问题编辑后另开会话回答、单会话 TXT / Markdown 导出；只处理聊商项目。

重命名先持久化再更新界面，拒绝空白、超长或控制字符。保存关闭/失败保留旧名称与草稿；首轮回答保留自定义名称，自动标题截断不切断 emoji 代理对。

编辑任意已完成问题时，先保存原会话，再保存一个新 ID 的前缀及修改后的草稿，之后才发出显式模型请求。旧会话和该问题以后的内容不变；新回答只携带之前的有效上下文，遵守重置位置、上下文开关、10 轮和 16000 字上限，使用当前人设与背景。容量满、保存关闭/失败在请求前阻止；失败/取消保留新草稿，不保存临时回答。保留既有取消与迟到结果隔离，无自动重试。

导出校验原会话结构，仅输出完整问答与背景，排除未发送草稿、临时预览、会话内部 ID 和连接配置。最大文本与 UTF-8 大小有界；Markdown 标题转义、正文使用动态长度代码围栏，消息内 HTML、链接和图片按原文显示。导出不承担清洗用户主动输入的敏感内容。使用 Android SAF 明确选择位置，不申请广泛存储权限、不写持久临时文件；取消/过期/重复回调按单个任务 ID 隔离，成功写入后才提示完成。文件为明文，界面有提示。

会话列表增加操作按钮及更新时间，避免重复标题片段；列表显式传递搜索/加载状态给 FlatList。测试需刷新 Android 无障碍节点，避免缓存造成旧标题或旧禁用状态的误报。普通及大字号检查实际截图和输入法展开位置。

无数据库、备份格式、后台或服务端改动，API 镜像仍为 chatq-api:stream-1.11.0。发布脚本核对现有私有配置、7 个容器、后台与旧下载文件；使用独立备份、新文件名和哈希验证，最新版指针最后原子切换。完整源码基于 canonical 1.11.0 源码叠加移动端改动，不采用本地过期后台。

后续可选能力：跨设备会话同步、显式分支树及多答案切换、聊天附件/图片。它们不属于本次三项功能的依赖。没有调用收费模型，没有微信/QQ 真机或 iOS 编译验证；Android 物理手机仍需要本人系统安装授权。
