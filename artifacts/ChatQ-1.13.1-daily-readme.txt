底部“对话”的本次更新：
1. 点会话标题旁“查找”，在当前会话完整问答中按关键词筛选并高亮。符号按字面匹配、忽略大小写，不查草稿与背景，不上传关键词；“关闭”恢复全部消息，系统返回键也可关闭查找。
2. 每条问题上方可“复制”原问题或“编辑”。消息显示回答时间，复制/编辑放在同一行，减少重复操作占位。
3. 请求失败会显示“重试本次问题”或“重试重新生成”，只有点击才再次请求。重新生成仍使用原问题，保留输入框中未发送草稿；回答已完成但本机保存失败时，只提供重新保存，不重复调用 AI。
4. 阅读旧消息时流式回复完成不会抢走阅读位置，右下“最新”可回到新回答；修复长会话跳转最新时空白的问题。停止提示可关闭，输入法展开时压缩非必要提示。
5. 关闭本机保存后，新建或切换会话会提示是否放弃当前临时问答和草稿。“留下”保留内容，“放弃并继续”才离开；本机写入失败会阻止切换。异步读取结果过期时不会覆盖新草稿。

保留会话重命名、编辑任意历史问题另开会话回答、TXT/Markdown 导出、流式回复、重新生成、全文会话搜索、人设与背景、上下文开关/重置。编辑另开会话保留原记录及后续消息；导出由系统选择保存位置，文件为明文，只含完整问答、背景、人设名称和时间，不含草稿、临时预览或连接配置。消息中主动输入的敏感内容仍会导出，请自行检查；加密备份在“键盘 → 数据备份与恢复”。

最多 50 会话/每会话 100 轮；上下文最近 10 个完整轮次和本次问题最多 16000 字。旧数据及 v1/v2 加密备份兼容，无数据库迁移。成功回复计一次额度；失败不自动重发或切换模型，取消不能撤回已发生的上游费用。

保留拼音、九宫格、语音、可选云词库、英文纠错、话题库、人设、套餐额度、共享生成记录和更新中心。继续使用现有后台 AI 配置与 HTTP IP 内测连接，本次无需后端升级。

测试采用普通/130% 字号安卓模拟器及本机 HTTP 合成回答，不调用收费模型，不读取第三方聊天或轮询剪贴板。物理手机仍需要本人完成系统安装授权，未进行微信/QQ 真机验证。iPhone 仅源工程，无 IPA，文件导出目前仅新版 Android。
