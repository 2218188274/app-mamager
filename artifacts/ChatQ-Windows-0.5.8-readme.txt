聊商 Windows0.5.8预览版 · Windows10/11 x64

用法：聊天分析 → 导入文件/文件夹 → 选择哪位是我 → 核对预览 → 按需保存到资料库。资料库可搜索、改名、载入和确认删除；载入后仍需核对并允许模型调用。原文用当前Windows账号加密，最多20份/50000条/16MB，普通备份不包含原文；每次保存为新资料，不自动覆盖或淘汰。
分段分析：选择最近500/1000/2000条 → 逐段核对 → 确认最多21次调用 → 主动生成。每段200条/24000字符，单条长消息在1600字符处明确缩短，超过20段要求减少范围。每次请求75秒，总任务10分钟。中断后完成的分段只留当前进程，再次点击生成才继续；范围、身份、问题、条数、人设或API改变后不复用。综合结果可查看分段摘要和消息依据，报告可导出TXT。
不会自动恢复跨次进度、后台分析或发送消息；供应商可能按请求收费。真实微信接入、QQ持续AI、正式签名、跨平台数据迁移、媒体/未知格式及真实软件硬件验收仍待完成。安卓1.29.2和后端未改动，正式收款关闭。
