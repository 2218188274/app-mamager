选会话 → 确认哪位是我 → 核对化名摘录和API → 勾选并生成。免费自备API；导入/另存无AI调用。分析仅基于所选最近文本，给出消息编号依据、下一步、话题和回复建议；需要自己在「我的API」配置供应商。
「导出聊天文字」支持当前会话最近200条或全部已导入文字，JSON/CSV可再导入，TXT便于阅读；原文是明文，媒体不包含，显示实际条数。不会写入普通会话、消息助手或云端。导出分析TXT不附带原始聊天。
修复首尾空格丢失、最长CSV转义回读、原始文件覆盖；取消/失败保留旧目标，成功后原子替换。窄窗和200%字号保持滚动和固定保存/停止按钮；版本号从程序版本读取。
