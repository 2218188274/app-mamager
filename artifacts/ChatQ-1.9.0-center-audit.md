# 聊商 1.9.0 功能与发布盘点

本次完成安卓使用中心四项功能。入口在主应用底部“键盘”；生成记录仍在底部“记录”，输入法 AI 面板也提供“记录”。

- 额度与套餐：GET /api/aikeyboard/account 使用已有应用与设备认证，读取真实成功次数、每日额度、UTC 重置时间、有效订阅与本应用启用的套餐。计算规则与生成共用，不调用模型。当前后台没有启用套餐（0 项），购买渠道尚未接入；没有模拟价格、扣款或开通按钮。
- 统一记录：安卓两端共用 chatq-generations.db，保存主动生成成功的回复及 AI 话题，包含来源与类型。旧版 SQLite 记录一次性事务迁移，保留多轮候选；写入成功后清理旧副本。主应用可搜索、复制、逐条删除、清空与关闭新记录保存；键盘显示最近 10 条并由用户点选填入，绝不自动发送。
- 备份与恢复：系统文件选择器导出 .chatqbackup，AES-256-GCM、随机盐/IV、PBKDF2-HMAC-SHA256（120000 次）。密码 8–128 字符，不可找回。包含本机记录、人设、键盘偏好、词库与收藏；排除连接码、设备身份、供应商密钥、额度/订阅及记录保存开关。安卓系统自动备份/设备迁移已明确排除，文件仅由用户主动导出。最大 10000 条记录、16MB 明文内容。
- 恢复先解密校验并预览，再确认合并。记录按 UUID 去重，收藏和词库合并；已有键盘偏好优先，人设同 ID 内容冲突另存确定性恢复副本。超过词库/人设上限时整次恢复失败；SQL 事务与偏好恢复日志用于异常回滚和进程中断恢复。错误密码/损坏文件不修改数据。
- 更新中心：主动检查同服务器 /downloads/chatq-android-latest.json，展示版本、日志、体积、SHA-256；不自动轮询或安装。下载拒绝跳转和超长内容，验证哈希、包名、版本及现有安装的签名，再打开系统授权/安装界面。当前发布 arm64 内测 APK；最新版指针与版本文件均在服务器。

验证覆盖模拟器和真实 Android InputConnection，具体结果见同版本 validation.md。本轮不调用收费模型；主应用/键盘生成持久化联调使用本地 HTTP 测试响应，额度接口使用真实数据库只读核对。

仍需完成：微信、QQ 真机安装回归；后续新版本真实在线覆盖安装；正式域名 HTTPS、正式签名、支付渠道及后台套餐上架。iOS 保留工程与结构检查，本轮安卓共享记录、文件备份和更新安装不能视为 iPhone 已交付。上游 AI 偶发连接失败仍需持续观察，不自动重试。

服务器已备份数据库和旧 API 源码/运行文件，API 采用小增量镜像 chatq-api:center-1.9.0，避免在低磁盘服务器全量构建。旧安装包/源码、私有连接配置、管理员前端及其他项目保留。发布核验见部署记录。
