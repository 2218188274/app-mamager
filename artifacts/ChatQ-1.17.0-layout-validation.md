# 聊商 1.17.0 布局与日常使用验证

类型检查通过，86 项客户端单元测试通过。本轮改动主应用和安卓键盘布局，后端协议、运行代码与数据库不变。

Android 11 / API30、320×640 mdpi 模拟器，合成编辑框与本地 HTTP 服务：

- 69 项粘贴、润色、返回、编辑器与隐私流程通过。
- 10 项重新润色，11 项重试/取消/模式切换候选保留通过。
- 14 项长结果/九宫格返回，39 项拼音与九宫格候选，41 项工具入口/底部留白/导航检查通过。
- AI 布局各 14 项：正常、130%、200% 字号竖屏与 130% 横屏。
- 主应用各 30 项：正常、130%、200% 字号，检查首屏消息输入、固定生成按钮、导航、草稿保留及关系/场景选择持久化。没有生成收费 AI 请求。

截图复审修复了工具栏图标挤压 AI 助手文字、首页偏好露出不足，以及 200% 字号标题占据首屏的问题。大字号收起装饰性标题，粘贴与对话标签缩短但保留完整无障碍名称。最终应用包完成上述三档主应用验收；键盘实现未变的最终原生回归沿用同轮通过结果。浅色、深色、拼音、九宫格和横屏截图已人工复查。

测试改进：旧固定滑动起点在大字号下落入固定按钮区，改为使用实际滚动边界；主应用输入框使用系统 input tap 事件，避免零时长注入触摸导致测试无法激活输入框。保留实际点按与输入断言，没有以无障碍直接设焦点代替触摸验收。

APK 1.17.0 / versionCode22，com.jaxon.app.chatq，arm64-v8a、Android7.0+。延续原内测证书；签名及 16KB 对齐检查通过，arm64 与被测 x86_64 的 Hermes bundle 相同。测试应用未包含在交付 APK 内。
