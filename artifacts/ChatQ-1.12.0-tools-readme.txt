打开底部“对话”：
1. “会话”列表 → “重命名”：保存 1–40 字名称，已有问答不变。当前会话也可点“设置”重命名；自定义名称不会被首轮回答覆盖。
2. 任意已完成问题下点“编辑问题”，修改后“另开会话并回答”。新会话只携带该问题之前的有效上下文，采用当前人设与背景；原会话、后续回答和原来的草稿完整保留。成功回答计 1 次额度。
3. 编辑后重新回答需要开启本机保存，并有空余会话名额；容量满时可自行在会话列表整理，不会自动删除。先保存新草稿再发请求；停止或失败后在新会话继续输入。
4. “会话”列表 → “导出”，或当前会话“设置 → 导出记录”，选择 TXT 文本 / Markdown，再由系统选择保存位置。取消不修改会话。完整问答、人设名称、时间和背景会写入明文文件，未发送草稿、临时预览和连接配置不会导出。请妥善保管；需要加密时仍用“键盘 → 数据备份与恢复”。

重命名、搜索和导出在本机完成，不消耗 AI 额度。Markdown 将消息按原文展示，消息内 HTML、图片等不执行或自动加载。用户主动写进问题或背景的敏感信息仍属于导出内容，请自行检查。

保留实时流式回复、最后回答重新生成、全文会话搜索、人设和背景、上下文开关/重置。只有完整成功回答进入记录与上下文，未完成内容仅临时预览。流式失败不自动重试或切换模型；取消不能撤回上游已发生的费用。

最多 50 个会话、每个 100 轮，上下文最近 10 个完整轮次与本次问题最多 16000 字。旧会话和 v1/v2 密码加密备份兼容，无数据库迁移。

保留拼音、九宫格、语音、可选云词库、英文纠错、话题库、人设、额度套餐、共享生成记录、备份和更新中心。使用既有 HTTP IP 内测连接和后台 AI 配置。本次仅更新移动端，API 服务继续使用 1.11.0。

测试使用本机 HTTP 合成回答及普通/130% 字号安卓模拟器，不调用收费模型；未进行微信/QQ 真机验证，手机仍需本人完成系统安装授权。iPhone 仅源工程，无 IPA，文件导出目前仅支持新版 Android。
