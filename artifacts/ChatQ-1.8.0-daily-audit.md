# 1.8.0 功能与版块盘点

已具备：真实 AI 回复、语气与候选数、人设/关系/场景、背景目标、离线话题库与接话、AI 找话题、主应用回复记录搜索与复制、全键盘拼音、九宫格、联想、自定义词、英文纠错、可选云词库、语音预览后插入，以及网页后台的应用、用户、订阅、统计、AI 配置和试聊。

## 本轮补齐

- 收藏互通：原有主应用收藏一次迁移到安卓共用存储，保留键盘新收藏；取消收藏后不会被旧数据重新加入。键盘增加“我的收藏”和明确的离线状态。
- 使用引导：显示键盘是否启用、是否为当前输入法；从系统设置回来自动刷新；提供试打区和清空入口。
- 帮助与反馈：常见问题、隐私与联网功能说明、版本信息及可复制的问题反馈模板。模板不含连接码、设备 ID、密钥和聊天。
- 无障碍：布局、主题、按键高度选项补充角色、选中和禁用状态。已检查 320 dp、130% 字号下新增页面及键盘收藏；未完成全面 TalkBack 人工审计。

## 仍缺少或待补齐

| 优先级 | 项目 | 当前情况 |
|---|---|---|
| P1 | 账号与套餐/额度页面 | 后台已有用户与额度控制，手机主要在超限时显示错误，缺少主动查询和清晰的剩余额度展示。 |
| P1 | 键盘生成记录与主应用统一 | 主应用回复保存在 SQLite；原生键盘生成的回复暂未汇总进此记录页，应加入用户可控的保存开关后再统一。 |
| P1 | 正式使用配置与兼容性 | 需要域名/HTTPS、正式安卓签名、微信/QQ 真机及不同厂商系统验证。当前仍为 IP HTTP 内测和既有测试签名。 |
| P2 | 用户数据导出/恢复与跨设备同步 | 人设、词库、收藏和记录为本机数据；没有账户云备份或恢复入口。需要明确选择范围、加密和用户主动授权。 |
| P2 | 在线反馈与版本更新中心 | 已有复制反馈模板；尚无工单收集、处理状态或应用内版本更新入口。 |
| P2 | iPhone 安装与验证 | 有工程，缺 Mac、开发者签名、Xcode 编译和真机验证；本次安卓收藏互通未移植到 iOS 扩展。 |

## 巡检边界

本轮没有新增自动读取聊天、剪贴板轮询、自动发送、付费 AI 自动重试。离线回归与本地 HTTP 测试不消耗 AI 额度，未重复调用付费模型。之前已验证真实 AI，但上游偶发连接失败的根因仍未确定。

线上后台的菜单修复已存在于服务器和 1.7.0 源码归档；当前本地 admin 工作副本较旧。本轮只对照检查，不以旧副本替换线上后台。服务器 API 健康，剩余磁盘约 1.6 GB；继续本机构建，保留数据库、密钥、其他项目及旧版下载。
