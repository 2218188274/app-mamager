# 聊商支付配置检查 · 后端 1.23.1

用户已确认尚未开通正式微信/支付宝商户，本轮完善支付功能和配置检查，保持真实收款关闭。

## 修复与使用

- 原配置校验会接受格式正确的示例商户值与示例域名。新增占位值、保留域名、HTTPS、根地址及固定回调路径校验；正式配置不齐备时关闭购买。
- 区分未指定文件、文件缺失、不可读、非普通文件、权限过宽、超过 32KB、JSON 错误与字段错误；支持 Windows 编辑器保存的 UTF-8 BOM。诊断仅输出脱敏字段提示。
- 账号页准备状态、实际下单及运维检查共用套餐校验；区分商户配置无效、应用不匹配、销售关闭和套餐未上架。
- 服务镜像内置 node scripts/payment-readiness.mjs，可直接通过 docker exec chatq-api-1 执行。--config-only 不需要数据库；无参数使用只读事务检查应用、套餐和待核对订单数。返回码 2 表示准备不足，1 表示参数或数据库错误。
- configurationReady 仅表示配置齐备，livePaymentsVerified 为 false；不会自动开通收款，不创建订单，不访问支付网关，不调用收费 AI。

## 发布范围与限制

仅后端补丁。Android 仍为 1.23.0 / versionCode34，无主应用、键盘、资源或布局变化，不重复打包，也不将本轮后端验证称作手机验证。既有 APK、源码归档、更新指针、数据库、密钥和回滚备份保留；线上核验以同前缀 deployment.json 为准。

正式收款仍需真实商户及通道、私有配置、批准的套餐价格与实际付款/回调/查单/退款验收。配置检查通过不能替代商户侧验证。自动退款、自动权益扣减、跨档补差价和自动续费仍未实现，沿用人工核对状态。
