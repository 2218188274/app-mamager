# 消息助手重连与发送隔离审查 · 2026-11-04

首次新增回归在修复前实际失败：`late old startup success cannot mark replacement connection ready`。触发顺序为连接A未完成→暂停A→建立连接B但尚未完成→A迟到成功；旧实现只检查当前lifetime非空，导致B被提前标为就绪。

审查同时覆盖旧连接的断开、失败、同账号消息和旧发送结果。旧回调使用共享状态可能误停新会话；旧发送失败按相同ruleId暂停好友，可能影响用户重新连接后的会话，或因旧记录已清理而停止新连接。

修复：每次Start捕获独立run、CTS、adapter与配置快照，接收和断开回调带原始归属；只有本次连接能改变其就绪状态。发送失败根据原run/config/account/peer决定是否暂停，旧失败只维护历史unknown，不重试、不污染新上下文。旧行不存在时不影响新连接。接收/生成异常也不得跨run停止。

新增16项可观察回归，连接器故意忽略取消：迟到启动成功/失败、旧断开与旧消息、新连接独立就绪、旧发送失败、已清理旧行、历史未确认记录保留、新连接继续生成确认草稿。原有白名单、当前未知发送暂停、人工接管、额度和上下文隔离检查继续通过。
