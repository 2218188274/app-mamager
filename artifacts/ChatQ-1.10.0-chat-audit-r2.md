# 1.10.0 交付审计

独立 AI 对话入口、结构化多轮上下文、按会话选择人设已实现。继续共用现有后台 AI 配置、用户状态校验、额度、取消与编号防重放。模型请求只含当前会话选定上下文，不从其他应用读取聊天或轮询剪贴板。

新增本机 chat_sessions 表，GenerationStore v1→v2 无损升级，原 IME 共享回复/话题记录仍保留。备份 JSON v2 增加会话，外层仍为现有 AES-GCM 加密格式；旧 JSON v1 可导入。恢复的人设冲突副本会同步映射到对应会话，避免会话误用本机同 ID 的其他人设。

仍属后续体验能力：逐字流式输出、单条回答重新生成/编辑分支、会话全文搜索。当前已支持完整回答、停止、复制、新建/继续/删除、本机备份和恢复。它们不是此次多轮对话的未完成依赖。

保持旧 APK、源码包、数据库、私有密钥和回滚备份。API FROM fixes-1.9.1 只覆盖八个 dist JS 文件，无数据库迁移。源码基于 canonical 1.9.1 包叠加手机工程及本轮服务器变更，保留现有后台，排除环境文件、数据库、构建输出与测试 APK。公网下载逐字节校验后，最后切换更新指针。
