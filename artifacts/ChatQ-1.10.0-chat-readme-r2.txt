聊商 Android 1.10.0（构建 13，内部测试版）

安装：下载 ChatQ-1.10.0-chat-arm64.apk，直接覆盖安装旧版以保留本机数据，不要先卸载。适用于 arm64-v8a、Android 7.0 及以上。

独立 AI 对话：打开主应用底部“对话”。输入问题后点“发送”，可连续多轮聊天；成功回答共用原有 AI 额度。API 地址、模型和密钥沿用后台现有 AI 配置，不需要在手机重复填写模型密钥。

人设与上下文：点击对话顶部的人设设置。可选择已有或自建人设卡，填写当前会话背景，开关历史上下文或重置上下文。只影响当前会话后续回答，键盘人设保持原选择。最近 10 个完整轮次与当前问题合计最多 16000 字；输入最多 2000 字，背景最多 1000 字。重置上下文会清除背景并停止携带旧轮次，但保留本机消息。

会话：可新建、继续、删除；本机最多 50 个会话、每个 100 轮，不自动淘汰旧对话。草稿自动保存，停止生成会保留输入文字；离开对话页或进入后台会停止尚未完成的请求，不自动重试。保存失败时保留可见回答，可单独重试保存本机记录，无需再次请求 AI。

数据：会话保存在本机，并纳入密码加密备份。备份新版支持对话，旧版备份仍可导入；同 ID 的冲突对话与人设分别保留副本。记录页的“保存本机记录”开关同时适用于对话；关闭后新内容仅临时保留。清空回复与话题记录不会删除独立对话，会话可在“对话→会话”中删除。服务端不持久保存这项功能的对话历史，生成时会把当前问题、选定上下文、人设与背景发给所配置的模型服务。

取消为尽力中止：已完成请求与模型服务已经产生的费用无法撤回。AI 内容可能有误，请核实重要信息。

已完成本机 HTTP 模型协议测试、安卓 API 30 模拟器 UI 与数据验证，包括 320×640 和 130% 字号。没有调用付费 AI 做重复测试。安卓真机安装仍需本人系统授权，不能把这些结果视为微信/QQ 真机验证。iPhone 仅同步源工程，未交付 IPA。
