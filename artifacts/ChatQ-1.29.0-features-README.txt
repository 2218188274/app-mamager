聊商 1.29.0 / Android 构建43

聊天对象档案：保存不同对象的人设、关系、场景、表达分寸和目标，主应用与键盘共用
导入本机图片表情：预览、改名、删除、收藏、最近使用，并纳入加密备份
账号密码确认注销、云端同步容量查询和版本校验删除；防止注销并发重建及删错已切换空间
长截图在本机先分段再缩放，逐段识别和核对，支持按原顺序合并文字；兼顾小屏和大字号

怎么使用
1. 人设卡片中心 → 管理聊天对象 → 保存当前偏好；键盘“更多人设”中切换对象。最多30个。
2. 发现 → 表情包 → 图片表情 → 导入我的图片表情。最多20张，每张自动缩放到128KB以内；键盘“表情→图片→收藏/最近”直接查看。预览不发送消息。
3. 我的 → 账号管理 → 注销账号，需当前密码和“注销账号”确认；必要匿名交易记录保留。本机API、图片和会话不自动删除。
4. AI对话 → 加密会话同步 → 查看容量；删除需输入“删除云端”并再次确认，持完整同步码的设备拥有空间管理权限，本机会话不删除。
5. 截图辅助 → 选择长截图并分段。原图最多20MB、8段；每段重叠120像素，逐段识别与核对后按顺序合并，删除重复文字并精简至1000字再用于回复。不会自动批量调用API。

对象和导入图片进入本机加密备份；含新功能的备份需1.29.0或更新版本恢复，旧备份仍可导入。恢复后的新对象库需手动选择对象。

验证：应用201项、后端70项；隔离PostgreSQL新增27项及原账号39项；安卓原生44项；普通/200%字号各26项模拟器检查通过。没有调用真实付费AI或发送聊天。
