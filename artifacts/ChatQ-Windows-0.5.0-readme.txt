打开“聊天分析”→选择导出文件→确认哪位是我→核对化名摘录和当前API→勾选允许→生成分析。
支持 messages.json、messages.csv、messages/*.json 及聊天数据ZIP，兼容安装包静态字段所示的 Session/Messages 和 AgentMessage。不是把导出程序安装包导入聊商，也不会运行其EXE/DLL、扫描或解密微信数据库、读取联系人清单或跟随manifest文件路径。
可选最近50/100/200条文本、1–10条回复建议。显示实际发送条数、长消息缩短与媒体排除；已知称呼、手机号和邮箱被替换，仍需本人核对预览。点击生成才直连自己的API，软件免费、正式收款关闭，模型费用由供应商计收。
结果包括有消息编号依据的观察、下一步行动、延续话题、可复制/继续润色的回复。编辑问题可聚焦新的分析；改身份/范围/问题/条数/API会使旧结果失效并取消请求。宽屏双栏、窄屏/大字号纵向、主按钮固定底部，完成后先显示总结。
导入与报告仅在本次进程暂存，不写普通会话、消息助手、云端或通用备份，不自动发送。退出需重新导入；可主动导出分析TXT（明文，只含报告、不含聊天原文）。当前不支持全文分段分析或图片/语音理解。
