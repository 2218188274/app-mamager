1. 对话回答支持原生 Markdown 排版、代码块单独复制，外链确认打开；不执行 HTML 或自动加载远程图片。

5. Jeepay下单、外部收银台、主动查单、签名回调及幂等开通适配已加入。商户系统尚未完善，正式渠道/密钥/HTTPS未配置，真实收款保持关闭。接入要求见 server/deploy/PAYMENTS.md。

会话默认保存在本机；开启同步后以本机AES-GCM加密密文存入服务器。同步码只在本机保存，不随请求发给服务端。当前IP是HTTP内测访问，正式使用应配置HTTPS保护接口认证。文本导出包含历史回答版本、文本附件；图片/PDF不嵌入，请使用加密备份迁移原件。
