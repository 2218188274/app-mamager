# 1.13.1 AI 对话审核与修复

范围为聊商主应用 AI 对话的保存、切换、重试、查找、滚动和界面；键盘引擎、后台、服务端和数据库格式没有改动。

确认并修复：关闭本机保存时，flush 返回 false 仍直接打开新会话，导致临时问答/草稿在没有提示时离开。现在显示明确的放弃确认，“留下”不改当前内容；真正写入异常继续阻止切换。异步初次读取/切换使用修订号、active/mounted 状态和原会话对象身份，避免迟到结果覆盖新状态；受控逻辑测试验证旧读取不能打开覆盖新草稿或正在生成的会话，不将其称为生产崩溃日志观察。

原界面在生成/保存/空闲阶段变化时无条件重新滚到底部；修复为根据用户阅读位置跟随。长会话跳到最新时还复现过空白，现关闭 Android 子视图裁剪，保持虚拟化，并区分显式跳转与用户拖动，避免布局调整误判为用户离开底部。相关界面检查用实际手势读旧消息，完成回复后比对旧问题的位置，再点击“最新”确认完整新回答可见。

当前会话内查找仅遍历该会话完整问答，字面正则转义、忽略大小写、关键词最多200字。高亮仅为原文字片段，不渲染 HTML，不加载远程内容；最多80个高亮，重组后与原文逐字相同，防止长重复回答创建大量子视图。筛选不改会话/上下文；重新生成始终按实际最后一轮 ID 判断，不把筛选结果中的最后一条当成可替换答案。

失败重试是显式操作：普通失败重发当前问题，重新生成失败保持原问题与旧答案；编辑分支保存成功之后才允许重试修改后的问题，分支预检失败不误发原草稿。保存已完成回答失败只提供本机保存重试。取消/编辑/切换会清理重试状态；不自动重发或改变提供商。用户明确点击复制问题时才访问剪贴板；测试只核对模拟器中本次主动复制的合成问题，没有轮询或读取第三方内容。

问题复制/编辑同行、回答时间、停止提示关闭、输入时提示压缩和按需“最新”按钮改善小屏阅读。触控按钮保持至少48dp，正文/高亮按共享配色显示。普通/130%字号、输入法展开、错误和空结果状态进行 release UI 回归。

保留50会话/100轮、上下文10轮/16000字、原数据及备份格式。无服务器/数据库变更，不调用收费模型。发布使用新文件名及独立源码备份，核对私有配置、7容器、68个后台文件、111个服务端源码文件及29个旧APK/源码下载；公网文件完整哈希核验后最后切换版本指针。

后续按日常影响排序：P2 安全的 Markdown 富文本/代码段展示；P2 跨设备账号与显式会话同步；P2 分支树/多答案对照；P3 主动上传附件/图片。Android16边到边显示仍需要对应系统实测。物理手机仍受系统安装授权限制，未进行微信/QQ真机验证或iOS编译；本轮验证使用模拟器、本机HTTP和受控状态。

最终视觉复核发现字数/额度提示沿用横向布局的flex:1，在纵向输入区被压成零高度；1.13.1移除该flex并增加实际屏幕可见高度断言。1.13.0下载保留，未切换过最新指针。
