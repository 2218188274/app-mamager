聊商 1.28.0 / Android 构建40

截图支持本机裁剪、隐私遮挡和识别文字确认；确认后只用文字生成
我的 API 支持最多8套加密配置、模型列表搜索和独立图片能力测试
键盘支持两个常用工具自定义、最近工具和左右单手布局
修复截图框选手势在重绘及大字号滚动时中断；保持切换布局时的拼音输入

使用入口
1. 首页回复 → 选择聊天截图 → 裁剪与遮挡 → 应用编辑；可直接生成，或点“识别文字后确认”，核对说话者和文字后确认，再点生成。识别与生成会调用自己的 API；图片编辑不调用 AI。
2. 我的 API → 新增 API 配置 → 填地址与密钥 → 获取模型列表（也可手填）→ 保存。支持最多8套配置，切换后主应用与键盘共用。文本测试和图片测试均须主动点击，可能产生供应商费用。
3. 键盘“更多”或主应用键盘设置 → 设置两个常用工具及左/右单手；最近工具仅记录工具入口。窄屏与横屏自动使用全宽；单手侧栏可切换方向、恢复全宽。

验证
类型检查、175项JS回归、30项新增原生检查、44项API回归、235项偏好/词库回归通过。普通字号52项、200%字号47项主流程检查，全键盘/九宫格单手9项和横屏4项检查通过。均使用模拟器/合成图片/本地接口；无真实付费AI请求、无消息发送。实际上传图片裁剪尺寸和遮挡像素已检查。
